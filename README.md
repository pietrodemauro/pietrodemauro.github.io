# Personal Academic & Research Website

A lightweight, modern, responsive personal website tailored for **Automation Engineering, Robotics, and Artificial Intelligence** researchers and engineers. 

Live ready to be hosted on **GitHub Pages**.

## Features

- **Profile & Biography**: Portrait picture, PhD status badge, research statement, and social/contact badges.
- **Academic Background**: Clean interactive vertical timeline (PhD, Master's, Bachelor's).
- **Core Research Areas**: Dedicated cards highlighting Robotics, Intelligent Control, and AI.
- **Dynamic GitHub Repositories**: Automatically queries GitHub's REST API to list your latest public repositories with live stars, forks, language badges, and links.
- **Dark Tech Theme**: Modern palette with cyan/blue accents and subtle glow effects suited for robotics & engineering.
- **Fast & Zero Build Tools**: Pure semantic HTML5, CSS3, and vanilla modern JavaScript (no Node.js/npm or build step required).

## Quick Setup Guide

1. Put your profile picture named `profile.jpg` into this directory.
2. In [script.js](file:///home/pietro/Documents/Code/Github-site/script.js), set `GITHUB_USERNAME = "your_actual_username"`.
3. In [index.html](file:///home/pietro/Documents/Code/Github-site/index.html), customize your university name, degrees dates, and contact email.
4. Push to GitHub and enable **GitHub Pages** in your repository settings!
